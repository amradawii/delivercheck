How email delivery works

  1. {{ icon("inbox", 20) }} MX

    Tells other mail servers which host receives incoming email for your domain.

  2. {{ icon("shield-check", 20) }} SPF

    Lists the mail servers and sending services authorized to send email using your domain.

  3. {{ icon("key", 20) }} DKIM

    Adds a cryptographic signature to each message so receivers can confirm it was not altered.

  4. {{ icon("file-check", 20) }} DMARC

    Tells receiving servers what to do when SPF and DKIM fail alignment, and where to send reports.

  5. {{ icon("lock", 20) }} TLS

    Encrypts email in transit between mail servers so messages cannot be read or tampered with.
